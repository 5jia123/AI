台灣薪資—物價螺旋機制之非對稱性檢定 停滯性通膨預期下的動態傳導實證

本研究聚焦台灣勞動市場在面臨物價急升與回落時的結構性調整彈性。透過台灣 AREMOS 總體經濟資料庫 的 CPI 與受雇員工實質/名目經常性薪資數據，檢驗新凱因斯工資僵固性與非對稱傳導效應。

AREMOS 資料庫 (PRICEM / EARNM) 新凱因斯工資向下僵固 (Wage Rigidity) HAC (Newey-West) 穩健標準誤 SVAR 脈衝衝擊反應函數 (IRF)
Section 01

研究假說與經濟學理傳導機制

H₁
核心研究假說 (Core Hypothesis)

CPI 年增率對經常性薪資成長的傳導具備「非對稱性」與「時間遞延性」

在物價劇烈攀升時期，由於勞資合約調整時滯與資方風險規避，名目經常性薪資上調呈現僵固；但在通膨回落階段，雇主亦無足額之超額補償機制。這使得勞工的「實質薪資成長率」在整個通膨週期中呈現系統性下偏 (Systematic Downward Bias)，形成生活成本受損的棘輪現象。

新凱因斯工資僵固性 (Wage Rigidity)

合約談判往往落後於即時物價波動。名目薪資通常具備向下僵固；但在高通膨階段，台灣企業雇主普遍傾向以一次性年終獎金、非經常性紅利代替經常性底薪的調升，避免未來營運成本結構僵化，從而壓抑常態薪資向上彈性。

傳導結果：$\partial \text{Wage}^{\text{regular}} / \partial \text{CPI}^+ < \partial \text{Wage}^{\text{total}} / \partial \text{CPI}^+$

工會談判力量與黏性資訊預期

依據黏性資訊理論 (Sticky Information) 與適應性預期假說，一般受僱勞工在察覺生活成本上升後要求工資補償存在時滯。若外生供給面衝擊（如全球原物料與能源價格暴漲）引發進口成本型通膨，廠商利潤空間受壓縮將進一步阻斷工資向物價的良性傳遞。

傳導結果：長期通膨預期脫錨時，實質薪資產生持續性負向偏離。
Section 02

計量模型設定與非對稱性分解 (Specification)

為檢定物價上漲與下跌對薪資影響的非對稱性，模型將消費者物價年增率分解為正向通膨衝擊 ($\Delta \text{CPI}^+$) 與負向/放緩通膨衝擊 ($\Delta \text{CPI}^-$)，建立如下動態回饋方程式：

$$ \Delta W_t = \alpha + \sum_{i=1}^{p} \rho_i \Delta W_{t-i} + \sum_{j=1}^{q} \beta_j^{+} \Delta \text{CPI}_{t-j}^{+} + \sum_{j=1}^{q} \beta_j^{-} \Delta \text{CPI}_{t-j}^{-} + \gamma \mathbf{X}_t + \varepsilon_t $$
非對稱假說檢定：$H_0: \sum \beta_j^{+} = \sum \beta_j^{-}$ （Wald 非對稱性檢定）
$\Delta W_t$ 台灣受雇員工名目經常性薪資之年增率 (%)。
$\Delta \text{CPI}_{t-j}^{+}$ 物價年增率上升衝擊：$\max(\Delta \text{CPI} - \tau, 0)$。
$\Delta \text{CPI}_{t-j}^{-}$ 物價年增率回落衝擊：$\min(\Delta \text{CPI} - \tau, 0)$。
$\mathbf{X}_t, \varepsilon_t$ 控制變數（失業率差、GDP成長率）與 HAC 殘差項。

AREMOS 資料清洗與計量分析程式碼

wage_price_spiral_asymmetry.py 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller

# ==============================================================================
# 1. 讀取與基礎清理 (處理 AREMOS CSV 前綴標頭與編碼)
# ==============================================================================
raw_df = pd.read_csv("AREMOS_DATA.csv", skiprows=3, encoding="cp950")

# 欄位重新映射：Date, CPI_YOY (CPI年增率), WAGE_YOY (經常性薪資年增率)
df = raw_df.rename(
    columns={
        raw_df.columns[0]: "Date",
        raw_df.columns[1]: "CPI_YOY",
        raw_df.columns[2]: "WAGE_YOY",
    }
)[["Date", "CPI_YOY", "WAGE_YOY"]]

# 清理日期格式 (例如: "2023M01" 轉為 "2023-01")
df["Date"] = pd.to_datetime(df["Date"].astype(str).str.replace("M", "-"))
df = df.dropna().sort_values("Date").reset_index(drop=True)

# ==============================================================================
# 2. 單根檢定 (ADF Test) - 確認時間序列平穩性
# ==============================================================================
def test_stationarity(series, name):
    result = adfuller(series.dropna())
    print(f"=== {name} ADF 檢定 ===")
    print(f"ADF Statistic: {result[0]:.4f}")
    print(f"p-value: {result[1]:.4f}")
    if result[1] < 0.05:
        print("結論：拒絕單根假說，序列呈定態 (Stationary)。\n")
    else:
        print("結論：無法拒絕單根假說，建議進行差分處理。\n")

test_stationarity(df["CPI_YOY"], "CPI 年增率")
test_stationarity(df["WAGE_YOY"], "經常性薪資年增率")

# ==============================================================================
# 3. 建立落後期特徵與非對稱衝擊構建 (動態菲利浦曲線)
# ==============================================================================
df["CPI_LAG1"] = df["CPI_YOY"].shift(1)
df["CPI_LAG2"] = df["CPI_YOY"].shift(2)
df["WAGE_LAG1"] = df["WAGE_YOY"].shift(1)

# 分解非對稱通膨偏離 (閾值設為 2.0% 目標值)
df["CPI_POS"] = df["CPI_LAG1"].apply(lambda x: max(x - 2.0, 0))
df["CPI_NEG"] = df["CPI_LAG1"].apply(lambda x: min(x - 2.0, 0))

model_df = df.dropna()

# ==============================================================================
# 4. 最小平方法 (OLS) 與穩健標準誤估計 (HAC / Newey-West)
# ==============================================================================
X = model_df[["WAGE_LAG1", "CPI_POS", "CPI_NEG"]]
X = sm.add_constant(X)
y = model_df["WAGE_YOY"]

ols_model = sm.OLS(y, X).fit(cov_type="HAC", cov_kwds={"maxlags": 4})
print(ols_model.summary())

# Wald 檢定：檢定 H0: CPI_POS = CPI_NEG (對稱性檢定)
wald_test = ols_model.wald_test("CPI_POS = CPI_NEG")
print("\n=== 非對稱性 Wald 檢定結果 ===")
print(wald_test)

# ==============================================================================
# 5. 視覺化：雙軸走勢圖輸出
# ==============================================================================
fig, ax1 = plt.subplots(figsize=(11, 5))
color = "tab:red"
ax1.set_xlabel("Year")
ax1.set_ylabel("CPI YoY (%)", color=color)
ax1.plot(df["Date"], df["CPI_YOY"], color=color, label="CPI YoY")
ax1.tick_params(axis="y", labelcolor=color)

ax2 = ax1.twinx()
color = "tab:blue"
ax2.set_ylabel("Regular Wage YoY (%)", color=color)
ax2.plot(df["Date"], df["WAGE_YOY"], color=color, linestyle="--", label="Wage YoY")
ax2.tick_params(axis="y", labelcolor=color)

plt.title("Taiwan CPI YoY vs. Regular Wage Growth Rate")
fig.tight_layout()
plt.show()
